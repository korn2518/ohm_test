# 옴의 법칙 무한 문제은행

중학교 과학(2022 개정) 전기 단원 — 저항의 직렬·병렬 연결 계산 문제를 숫자만 바꿔 무한히 출제하고, 바로 채점하는 웹앱입니다.

- **평가 모드**: 20문항(직렬 10 + 병렬 10 유형 각 1문항), 끝나면 결과 자동 제출
- **무한 연습**: 전체 / 직렬 / 병렬 중 선택, 원할 때 "그만하고 결과 제출"
- 결과는 Google Apps Script를 통해 스프레드시트(요약 / 상세 / 학생별)에 쌓입니다.

## 결과 수집 연결 (최초 1회)
1. 새 구글 스프레드시트 → [확장 프로그램] → [Apps Script]
2. `apps-script/Code.gs` 내용 붙여넣기 → 저장
3. [배포] → [새 배포] → 웹 앱 / 실행: 나 / 액세스: 모든 사용자 → 웹 앱 URL 복사
4. `index.html` 상단 `SCRIPT_URL`에 URL이 이미 들어가 있습니다. 바꿀 때만 수정하세요.
